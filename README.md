# 📖 Mutabaah Yaumiyah ARMAS

Aplikasi pencatatan ibadah harian untuk anggota ARMAS. Aplikasi ini dibuat untuk membantu anggota memantau konsistensi ibadah, melihat perkembangan pribadi, dan meningkatkan semangat dalam menjalankan amalan sehari-hari.

## 🌐 Akses Aplikasi

**[Buka Mutabaah Yaumiyah ARMAS](https://mutazs21.github.io/aplkasi-mutabaah-armas/)**

Aplikasi dapat diakses melalui browser HP, tablet, maupun laptop.

## ✨ Fitur Utama

### 👤 Anggota

- Login menggunakan akun masing-masing.
- Mengisi catatan ibadah harian.
- Melihat dashboard perkembangan ibadah pribadi.
- Melihat riwayat mutabaah.
- Melihat detail catatan ibadah.
- Memantau konsistensi dan pencapaian ibadah.

### 🛠️ Admin

- Login menggunakan akun admin.
- Melihat perkembangan mutabaah anggota.
- Memantau aktivitas dan pencapaian anggota.
- Melihat leaderboard anggota.

### 🕌 Pencatatan Ibadah

Aplikasi menyediakan pencatatan beberapa amalan harian:

| Kategori  | Amalan                                              |
| --------- | --------------------------------------------------- |
| Sholat    | Tahajjud, Subuh, Dhuha, Dzuhur, Ashar, Magrib, Isya |
| Istighfar | Istighfar 100 kali                                  |
| Puasa     | Puasa                                               |
| Al-Qur'an | Jumlah halaman yang dibaca                          |

Pilihan pencatatan sholat:

- Tidak sholat
- Sholat sendiri
- Sholat berjamaah

## 🔐 Keamanan

Aplikasi menerapkan beberapa mekanisme keamanan, antara lain:

- Autentikasi anggota menggunakan PIN.
- Autentikasi admin dengan sistem tersendiri.
- Validasi sesi login menggunakan token.
- Pembatasan akses data berdasarkan identitas pengguna.
- Validasi data sebelum disimpan.
- Pemisahan hak akses anggota dan admin.

Data aplikasi dikelola melalui Google Sheets dan Google Apps Script.

## 🚀 Pengembangan

Project ini dikembangkan secara bertahap untuk meningkatkan kemudahan penggunaan, keamanan, dan kualitas visualisasi perkembangan ibadah.

Beberapa aspek yang terus dikembangkan:

- Penyempurnaan dashboard dan visualisasi data.
- Pengembangan analisis performa ibadah.
- Peningkatan responsivitas tampilan.
- Penyempurnaan fitur monitoring admin.

## 🎯 Tujuan Project

Mutabaah Yaumiyah ARMAS dibuat sebagai sarana untuk membangun kebiasaan ibadah yang lebih teratur dan konsisten.

Harapannya, aplikasi ini dapat membantu setiap anggota melakukan evaluasi diri serta saling memotivasi dalam meningkatkan kualitas ibadah sehari-hari.
